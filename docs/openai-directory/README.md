Real ChatGPT walkthrough recorded on 2026-11-10 with GetDot Reviewer Test connected to the dedicated sample ramen workspace. These files are review materials; the directory listing remains an unsubmitted draft pending Rick's review.

[Watch the demo](demo.mp4).

The video contains the five positive scenarios: accessible data discovery, revenue comparison with SQL, the published Ramen Sales Overview, a support dashboard draft with its priority filter, and an approved EUR reporting preference. The dashboard draft was not published. The recording includes a ChatGPT dashboard preview timeout, the successful retry, and an explicit follow-up to read the rendered dashboard values. The completed revenue card is reopened at the end.

Capture used genuine reviewer-window pixels through computer control at approximately one frame per second. Playback is accelerated 4x, retaining the relative timing between captured frames. No interface, chart or response was reconstructed. There is no camera, microphone, system audio or credential entry. The sample account and its data remain available for review.

The three PNGs are ordinary crops and resizes of genuine rendered frames, one for each starter prompt. Each is exactly 706 px wide and between 400 and 860 px tall.
